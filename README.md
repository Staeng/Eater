# Eater 먹킷리스트

먹고 싶은 곳을 두서없이 적으면 Claude가 카드로 정리해 주는 맛집 위시리스트예요. 폰에서 보는 걸 기준으로 만들었어요.

- 앱 주소: https://mukkit.vercel.app (Vercel 프로젝트 `eater`)

- 맨 위: 먹고 싶은 걸 적는 칸, `릴스 링크도 있어요` 체크(체크하면 링크 칸이 열림), 메뉴 사진, `정리해서 담기`
- 그 아래: 식당명·메뉴 검색, 지역(권역 → 구), 식사 종류, 정렬(등록순 · 가나다순 · 가까운 날짜 순 · 상암동에서 가까운 순, 열 때마다 등록순으로 시작)
- 카드: 왼쪽에 종류·이름·구·권역·메뉴·언제·메모, 오른쪽에 대표 메뉴 사진과 D-day 스티커, 아래 줄에 지도·릴스·고치기·지우기
- 카드를 누르면 폰에서는 네이버지도 앱이 바로 열려요(앱이 없으면 모바일 장소 페이지, PC에서는 네이버지도 웹). 링크가 없으면 식당명과 동네로 검색해요.
- 카드의 ‘고정’을 누르면 ‘우선’ 카드가 되어 정렬과 상관없이 맨 위에 붙어 있어요. 다시 누르면 풀려요.
- 이미 담은 곳(같은 네이버 장소, 링크, 또는 같은 구의 같은 이름)은 경고 창을 띄우고 다시 담지 않아요.
- 가게 이름만 대충 적어도(예: “자양동 인근 감탄쪽갈비”, “연희동 루이지 피자”) 네이버 지도에서 찾아 링크, 주소, 대표 메뉴, 음식 사진을 붙여요. 네이버 이름에 없는 ‘피자’ 같은 말이 붙어 있어도 단어별로 다시 찾아요.
- 캐치테이블: 네이버 블로그 글을 Claude가 읽고, 예약을 받는 곳이면 이름 옆에 ‘캐치테이블 예약’ 버튼을 달아요. 미리 예약해야 하거나 웨이팅만 받는 곳은 그 내용을 메모에 자동으로 적어요.
- 식사 종류: 소고기, 돼지고기, 닭·오리, 해산물, 한식, 면요리, 분식, 일식, 중식, 이탈리안, 프렌치, 스페인, 멕시칸, 아메리칸, 브런치, 태국, 베트남, 인도·네팔, 중동·지중해, 카페·디저트, 베이커리, 술집, 기타

디자인 규칙은 [DESIGN.md](./DESIGN.md)에 있어요.

## Vercel로 배포하기

1. https://vercel.com/new 에서 GitHub로 로그인하고 `Staeng/Eater` 저장소를 **Import** 합니다.
   설정(빌드 명령, 출력 폴더)은 `vercel.json`에 들어 있어서 그대로 두면 돼요.
2. **Environment Variables**에 다음을 넣습니다.

   | 이름 | 값 | 필수 |
   | --- | --- | --- |
   | `ANTHROPIC_API_KEY` | https://console.anthropic.com 에서 만든 API 키 | 예 (없으면 간단 정리 모드로만 동작) |
   | `APP_PASSCODE` | 앱에 들어갈 때 쓸 비밀번호 | 강력 권장 (없으면 주소를 아는 누구나 쓰고 지울 수 있음) |
   | `EATER_MODEL` | 기본값 `claude-haiku-5-5`. 더 꼼꼼한 판단이 필요하면 `claude-opus-5-5` | 아니요 |

3. **Deploy**를 누릅니다.
4. 프로젝트의 **Storage** 탭 → **Create Database** → **Upstash for Redis** → 이 프로젝트에 **Connect** 합니다.
   (`KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 들어가요.) 그다음 **Deployments**에서 최신 배포를 **Redeploy** 합니다.
   저장소를 연결하기 전에는 카드가 그 기기 브라우저에만 저장되고, 화면 위에 안내가 떠요.
5. 폰에서 주소를 열고 비밀번호를 한 번 입력한 뒤, 공유 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

지금은 GitHub 기본 브랜치가 `claude/beautiful-cannon-e81kwp`라서 Vercel이 이 브랜치를 운영(Production) 배포로 씁니다.

### 비용

한 곳을 담을 때 Claude를 세 번 불러요(메모 정리, 음식 사진 고르기, 캐치테이블·테이블링 판단).
기본 모델 `claude-haiku-5-5`로 한 곳에 약 3원이에요(`claude-opus-5-5`로 바꾸면 약 80원). Upstash Redis와 Vercel은 개인 사용량이면 무료 요금제로 충분해요.

## 동작 방식

| 부분 | 파일 | 하는 일 |
| --- | --- | --- |
| 화면 | `eater.html` | 한 파일짜리 페이지. `npm run build`가 `public/index.html`로 감싸서 내보냄 |
| 정리 | `api/parse.js`, `lib/prompt.js`, `lib/naver.js` | 메모(와 사진)를 Claude에 보내 JSON(식당명, 지도·릴스 링크, 메뉴, 종류, 시·구·동, 날짜)으로 받음. 그다음 네이버 장소(메모의 링크, 없으면 이름+동네 검색)의 메뉴판에서 대표 메뉴 이름과 메뉴 사진, 좌표, 네이버 분류를 가져와 채움 |
| 사진 | `lib/enrich.js` | 메뉴판 사진 몇 장과 손님 리뷰 사진 몇 장 중 실제 음식이 찍힌 사진을 Claude가 고름(로고·그림·외관·실내 제외). 고를 수 없으면 첫 메뉴판 사진 |
| 캐치테이블 | `lib/catchtable.js`, `lib/enrich.js` | 네이버 블로그 검색 결과로 예약/웨이팅/미리 예약 필요 여부를 Claude가 판단 |
| 다시 채우기 | `api/enrich.js` | 저장된 카드에 위 네이버·캐치테이블 정보를 다시 채움 |
| 저장 | `api/places.js`, `lib/store.js` | 카드 목록 (Upstash Redis) |
| 사진 | `api/photo.js` | 폰에서 줄인 JPEG을 저장하고 보여 줌 |
| 잠금 | `lib/auth.js` | `APP_PASSCODE`와 맞는지 확인 |

Claude 요청은 `claude-haiku-5-5`, effort `low`, 구조화 출력(JSON 스키마)을 써요. Opus 같은 모델로 바꾸면 안전 분류기가 거절할 때 서버에서 다른 모델로 넘기는 `fallbacks: "default"`도 켜지고, 계정이 이 기능을 받지 않으면 자동으로 빼고 다시 요청합니다.
Claude를 쓸 수 없을 때(키 없음, 사용량 초과 등)는 페이지 안의 간단 정리기(정규식)로 담고, 카드의 연필 버튼으로 고칠 수 있어요.

권역은 서울시 생활권 기준으로 계산해요.

| 권역 | 구 |
| --- | --- |
| 서울 도심 | 종로, 중, 용산 |
| 서울 동북부 | 성동, 광진, 동대문, 중랑, 성북, 강북, 도봉, 노원 |
| 서울 서북부 | 은평, 서대문, 마포 |
| 서울 서남부 | 양천, 강서, 구로, 금천, 영등포, 동작, 관악 |
| 서울 동남부 | 서초, 강남, 송파, 강동 |

경기는 북부(고양, 파주, 의정부, 남양주, 구리, 김포 등)와 남부로 나눠요.

## 내 컴퓨터에서 실행

```bash
npm install
APP_PASSCODE=1234 ANTHROPIC_API_KEY=sk-ant-... npm run dev   # http://localhost:3000
```

Redis 없이 `.data/dev-store.json`에 저장돼요.
