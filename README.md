# Eater 먹킷리스트

먹고 싶은 곳을 두서없이 적으면 Claude가 카드로 정리해 주는 맛집 위시리스트예요.

- 배포 주소(초안): https://claude.ai/artifact/9DYdfrRaCP1EvmmvXB4CWe
- 소스: [`eater.html`](./eater.html) (한 파일짜리 페이지)

## 화면 구성

| 위치 | 내용 |
| --- | --- |
| 맨 위 | 먹고 싶은 걸 적는 칸, `릴스 링크도 있어요` 체크박스(체크하면 링크 칸이 열림), 메뉴 사진 첨부, `정리하기` 버튼 |
| 상단 | 지역(권역 → 구) 드롭다운, 식사 종류 드롭다운, 식당명·메뉴 검색, 정렬(최근 담은 순 / 가고 싶은 날 순 / 예산 낮은 순) |
| 가운데 | 맛집 카드. 사진(없으면 종류별 그림), 식사 종류, D-day, 릴스 바로가기, 식당명, 구·동과 권역, 메뉴, 가고 싶은 날, 1인 예산, 담은 날 |

카드를 누르면 네이버지도로 이동해요. 링크가 없으면 식당명과 동네로 네이버지도를 검색해요.

## 동작 방식

이 페이지는 claude.ai 아티팩트로 올라가 있고, 아티팩트 런타임 기능을 씁니다.

- `sample`: 적은 메모(와 첨부 사진)를 Claude에게 보내서 식당명, 지도 링크, 릴스 링크, 메뉴, 식사 종류, 시·구·동, 1인 예산, 가고 싶은 날을 JSON으로 받아요. 보는 사람의 Claude 사용량을 쓰고, 처음 한 번은 허용 여부를 물어봐요.
- `db`: 카드를 `places` 컬렉션에 저장해요. 폰과 PC에서 같은 목록이 보여요.
- `assets`: 첨부한 메뉴 사진을 줄여서 올려요.
- Claude를 쓸 수 없으면 페이지 안의 간단 정리기(정규식 기반)로 대신 정리해요. 카드는 나중에 연필 버튼으로 고칠 수 있어요.

권역은 서울시 생활권 기준으로 페이지에서 직접 계산해요.

| 권역 | 구 |
| --- | --- |
| 서울 도심 | 종로, 중, 용산 |
| 서울 동북부 | 성동, 광진, 동대문, 중랑, 성북, 강북, 도봉, 노원 |
| 서울 서북부 | 은평, 서대문, 마포 |
| 서울 서남부 | 양천, 강서, 구로, 금천, 영등포, 동작, 관악 |
| 서울 동남부 | 서초, 강남, 송파, 강동 |

경기는 북부(고양, 파주, 의정부, 남양주, 구리, 김포 등)와 남부로 나눠요.

## 수정해서 다시 올리기

`eater.html`을 고친 뒤 Claude Code에서 같은 파일로 아티팩트를 다시 게시하면 같은 주소가 갱신돼요. 저장된 카드는 그대로 남아요.

페이지 맨 위에 `<!doctype html>`과 `<head>` 없이 내용만 있는 건 아티팩트 형식이라서예요. 게시할 때 플랫폼이 감싸 줍니다.
